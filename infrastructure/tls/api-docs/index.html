Grobase public API

Access

  • Every route needs a key in the apikey header. Without one, or with an unknown one, the gateway answers 401.
  • Each route has its own per-IP limit, counted once the key is accepted. Over the limit the gateway answers 429; the RateLimit-* response headers give the limit, what is left and the seconds until the reset.
  • Machine-readable document: /openapi.json (OpenAPI 3.1).
